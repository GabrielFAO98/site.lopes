# Vitrine Virtual — Lopes e Lopes

Catálogo online indexável de alta performance para a **Lopes e Lopes** (Materiais de Construção, Hidráulica, Elétrica, Tintas e Ferramentas) em Franca - SP.

Este projeto tem como foco a atração de tráfego local qualificado via SEO e a conversão direta de orçamentos e vendas via WhatsApp.
